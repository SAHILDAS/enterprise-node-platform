# Enterprise Node Platform

Production-grade enterprise Node.js microservice platform built with **TypeScript**, **Fastify**, **PostgreSQL**, **MongoDB**, **Redis**, **Kafka**, **Docker**, and **GitHub Actions**.

## Architecture

- API Gateway
- Auth Service
- User Service
- Notification Service
- Shared platform packages

## Tech Stack

- Node.js 24 LTS
- TypeScript
- Fastify
- PostgreSQL
- MongoDB
- Redis
- Redpanda (Kafka API)
- Prisma
- Mongoose
- Docker
- Turborepo

## Quick Start

```bash
pnpm install
docker compose up -d
pnpm dev
```
